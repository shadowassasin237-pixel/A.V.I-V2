A.V.I. FULL SOURCE

This is the complete source tree. Copy these files into your A.V.I. project.

Gemini normal replies use Gemini 3.1 Flash TTS (Kore) only. There is no pyttsx3 fallback for normal replies.
Gemini Live uses gemini-3.8-live.
Startup boot sound is generated by Windows winsound while the startup HUD animation runs.
Startup intro is displayed one line at a time with no blank lines and includes both creator sentences.

Install:
pip install -r requirements.txt
Run:
python app.py
